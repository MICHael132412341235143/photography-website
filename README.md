# photography-website
Project Purpose 

 

This project involves the complete redesign and redevelopment of an existing photography website for a client based in Fraserburgh campus. 

The client currently has a WIX photography website which has not been updated for about 5 years and would like a new, modern website while retaining the important sections, content and links from the existing site. 

The project will involve analysing the existing website, gathering and confirming client requirements, designing a new user interface, developing the website using C# and asp.net Core/CSHTML, and testing the complete system. 

The new website is expected to include sections such as a welcome page, about page, weddings, clients, pricing, pets, babies, and contact. Photography categories and their relevant subcategories will be confirmed with the client. Additional functionality, including a chat button, location/map feature, and an administration portal for managing photographs, will also be investigated and confirmed during the requirements gathering stage. 

The project will be completed by a 6-person team. The Project Leader will coordinate the team, manage communication with the client and work across different areas of the project depending on what needs to be done. The Project Leader will support team members when they need additional help and, when support is not required elsewhere, will primarily contribute to the development of the website. The remaining team members will have defined responsibilities covering development, documentation and project planning, low-fidelity wireframes, and high-fidelity UI/UX design. Team members will also support one another where required throughout the project. 

The overall aim is to produce a modern, responsive and user-friendly photography website that meets the clients’ requirements and provides an improved experience compared with the existing website.   

 

What the project involves 

 

Analysing the client's existing photography website and identifying areas for improvement. 

Gathering and confirming the client's requirements for the new website. 

Planning the structure, navigation and functionality of the website. 

Creating low-fidelity wireframes for the website pages and navigation. 

Developing high-fidelity UI/UX designs based on the approved wireframes. 

Developing the website using C#, ASP.NET Core and CSHTML/Razor. 

Creating and implementing photography categories and subcategories. 

Developing responsive layouts for desktop, tablet and mobile devices. 

Implementing features such as contact functionality, a chat button and a map/location feature, subject to client requirements. 

Designing and developing a database to manage relevant website data where required. 

Investigating and potentially implementing an administration portal for managing photographs. 

Implementing photograph uploading and category/subcategory management if the administration portal is approved. 

Integrating the client's photography, text and other content into the website. 

Testing the website for functionality, usability, responsiveness, accessibility and errors. 

Gathering client feedback and making agreed revisions. 

Completing final testing, deployment and project handover. 

Producing the required project documentation throughout the development process. 

 

Team/project structure	 

The project will be completed by a six-person student development team. The team will use a collaborative structure in which each member has a primary area of responsibility while also supporting other team members when required. 

The Project Leader will be responsible for overall project coordination, communication with the client, requirements gathering, task allocation and project planning. Rather than being limited to one area of the project, the Project Leader will work across the different areas when support is needed. This may include helping with documentation, planning, UI/UX, testing or other project tasks. When other team members do not require support, the Project Leader will primarily contribute to the development of the website alongside the development team. 

The Main Developer will lead the technical development of the website, with a particular focus on C#, ASP.NET Core, project architecture, database development and core functionality. The Main Developer will work closely with Aden and the Project Leader as part of the development team. 

The Developer, Aden, will be part of the development team and will help build the actual website. Aden will work alongside the Main Developer and Project Leader to implement website pages, features and functionality, assist with C#/ASP.NET Core development, and support testing and integration of the completed website. 

The Documentation and Project Planning Lead will be responsible for maintaining project documentation, including meeting records, requirements, project progress, development records, testing records, design decisions, client feedback and project planning documentation. 

The UI/UX Wireframe Designer will be responsible for creating low-fidelity wireframes that establish the structure and navigation of the website. This will include page layouts, button placement, navigation structures and user flows. 

The UI/UX Visual Designer will take the approved low-fidelity wireframes and develop them into high-fidelity designs. This will include colour schemes, typography, imagery, spacing, detailed layouts, responsive designs and prototypes where required. 

Although each team member has a primary role, the project will be collaborative. Team members will communicate regularly, review each other's work and aid where required to ensure that the final website is developed consistently and meets the agreed project requirements.
